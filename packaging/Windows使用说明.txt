Aside 1.1 — Windows x64

适用于 Windows 10/11 64 位 Intel / AMD 电脑。
双击 Aside.exe 即可运行，无需终端，无需另装 .NET，无需管理员权限。
首次启动会将随包运行库解压至系统临时缓存目录，可能需要几秒。

快捷键：Ctrl + Alt + Space。可在设置中录制任意带修饰键的组合。
快速输入在屏幕正中出现，保存后自动消失，新记录默认不置顶。
保存键可在设置中选择 Enter 或 Ctrl+Enter，Esc 取消。
主窗口底部点亮图钉可直接置顶；置顶上限默认 3 条，可在设置中调整为 1–20 条。
主窗口支持完整列表、仅显示置顶、细条三种状态。按住窗口任意空白处即可拖动。
拖到屏幕左右边缘，鼠标离开后完全隐藏、不留痕迹；鼠标移到原来的屏幕边缘即可唤回，拖离边缘解除隐藏。
右键事项可置顶、标记完成或删除；点击文字可直接修改。
输入条采用胶囊圆角，右侧圆形 ×、Esc 或点击外部均可取消，不提交内容。
设置中的「快速输入」独立调节输入条透明度，并与便签一起提供实时预览。
拖动置顶条目的文字可调整顺序；置顶已满时会要求选择替换。
关闭主窗口会隐藏至系统托盘；单击托盘图标重新打开，右键可快速记录、切换形态或退出。
可在设置中选择颜色、屏幕取色、透明度、始终置顶及登录启动。

数据：%LOCALAPPDATA%\QuietPin\inbox.json（为兼容旧版而保留）
设置也保存在此文件。请不要用 Mac 版 JSON 直接覆盖 Windows 版文件。
移动 EXE 后，请重新开关「登录时启动」更新文件路径。

此版本尚未进行 Windows Authenticode 代码签名。
从网络下载后可能出现 SmartScreen 的未知发布者提示。
请确认文件来源可信，再根据系统提供的选项选择运行；无需关闭系统防护。
